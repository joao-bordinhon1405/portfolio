Projeto API - 1º Semestre: Plataforma Socioeconômica

Parceiro / Cliente: FATEC São José dos Campos (Demanda de base acadêmica)

O Problema: Havia a necessidade de analisar, estruturar e cruzar grandes volumes de índices socioeconômicos das regiões federativas brasileiras. O desafio do grupo foi receber um projeto estruturado originalmente por alunos do 3º semestre e evoluir sua inteligência de dados para realizar cálculos automatizados e cruzamento de informações geográficas de forma eficiente.

Solução Desenvolvida: Desenvolvimento de um sistema focado no tratamento de dados socioeconômicos regionais. A aplicação recebe os indicadores das unidades federativas, realiza o cruzamento de dados analíticos e gera resultados que facilitam a visualização da disparidade ou crescimento entre as regiões brasileiras.

Tecnologias Utilizadas: HTML5, CSS3, JavaScript, Python, Google Colab

Contribuição Pessoal: Atuei na criação da interface visual do site / Ajudei a estruturar a lógica de cálculo dos índices.
